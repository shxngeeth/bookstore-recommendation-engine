# 📚 Bookstore Recommendation Engine

A Python-based recommendation system that suggests books to users based on **Jaccard Similarity** of purchase history.  
Includes a **Tkinter GUI** for interactive user selection and recommendations.

## 🚀 Features
- Object-Oriented Design (Book, User, RecommendationEngine)
- Jaccard Similarity–based collaborative filtering
- Tkinter GUI interface
- JSON data persistence
- Efficient set-based operations
